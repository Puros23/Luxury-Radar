# Luxury Radar

Selección editorial de productos extraordinarios disponibles online.

## Estado

Landing pública inicial para presentar el proyecto y facilitar la evaluación por plataformas y futuros anunciantes. El catálogo real todavía está en preparación.

## Principios

- Productos reales y verificables.
- Revisión editorial antes de publicar.
- Calidad frente a cantidad.
- Transparencia en enlaces de afiliación.
- Sin precios ni disponibilidad ficticios.

La aplicación local de rankings y el motor editorial se desarrollan por separado de esta landing estática.
